# Otzvuk

Нативное приложение для iPhone: записывайте аффирмации своим голосом, слушайте их по кругу,
воспроизводите задом наперёд и добавляйте фоновую музыку. Всё работает локально, без интернета.

Swift 5 · SwiftUI · AVFoundation · iOS 17+ · без внешних зависимостей.

## Как открыть и запустить

```bash
open Otzvuk.xcodeproj
```

1. Выберите схему **Otzvuk** и симулятор iPhone (или своё устройство) → ⌘R.
2. Для запуска на iPhone: Target **Otzvuk → Signing & Capabilities → Team** — укажите свой Apple ID/команду.
3. Тесты: ⌘U или
   `xcodebuild -project Otzvuk.xcodeproj -scheme Otzvuk -destination 'platform=iOS Simulator,name=iPhone 16 Pro' test`

Проект генерируется из `project.yml` (XcodeGen). Если правите структуру файлов: `brew install xcodegen && xcodegen generate`.
Готовый `Otzvuk.xcodeproj` уже лежит в репозитории, XcodeGen для обычной работы не нужен.

> Если папка проекта лежит в iCloud-синхронизируемом месте (например, «Документы»), сборка может падать на подписи
> (`resource fork, Finder information, or similar detritus not allowed`). Решение: собирать с
> `-derivedDataPath` вне этой папки или перенести проект в `~/Developer`.

## Где что хранится

- `Application Support/Otzvuk/Recordings/` — оригиналы записей (m4a, AAC 44,1 кГц) — **никогда не изменяются**;
- `Application Support/Otzvuk/Music/` — импортированные мелодии (копии файлов);
- `Application Support/Otzvuk/library.json`, `music.json` — списки;
- `Caches/Otzvuk/Reversed/` — развёрнутые копии (CAF, 16 бит, та же частота дискретизации). Кеш можно удалить: пересоздастся сам.

При запуске приложение удаляет файлы, на которые нет ссылок (остатки прерванной записи или обработки).

## Встроенная музыка и лицензия

Три мелодии («Рассвет», «Тихая вода», «Глубокий покой») **синтезированы с нуля** скриптом
`Tools/generate_music.py` (синусоиды, шум, реверберация; бесшовные 60-секундные петли).
Сторонних сэмплов и записей нет, поэтому нет и чужих лицензионных ограничений: они принадлежат владельцу проекта.
Пересборка: `python3 Tools/generate_music.py` (нужны numpy и `afconvert` из macOS).
Это не «студийная» музыка, а простые эмбиент-пэды. Если хотите другое звучание, добавьте свои файлы через «Файлы».

## Библиотека текстов

178 текстов в 11 категориях встроены в приложение (только текст, без аудио). Нажатие на текст добавляет его в список
«Хочу записать» (повторное — убирает). Из списка можно открыть запись: текст показывается над кнопкой записи, название
подставляется из текста. После сохранения запись пропадает из «Хочу записать», и сразу открывается следующий текст из списка (если он есть). Чтобы изменить тексты или категории,
правьте `Tools/affirmation_texts.txt` и `Tools/generate_text_library.py`, затем запустите генератор.
Это отступление от исходного ТЗ («без готовых аффирмаций») по прямой просьбе владельца проекта.

## Ограничения первой версии

- Состав очереди фиксируется при запуске: отметки записей, изменённые во время прослушивания, подействуют со следующего запуска.
  Режим «задом наперёд» (один переключатель на весь плейлист), паузы, громкость, музыка и таймер применяются на лету.
- Порядок записей — по времени создания (перестановки нет).
- Только iPhone, портретная ориентация.
- Громкость регулируется внутри приложения; системная громкость — как обычно кнопками.
