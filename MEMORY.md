# MEMORY — Otzvuk

## 2026-10-11 — Архитектура и стек
**What was decided:** SwiftUI + AVFoundation, iOS 17+, проект из XcodeGen (`project.yml`), без внешних зависимостей. Голос и музыка — два отдельных `AVAudioPlayer`; паузы между записями — таймер (Task), а не тишина в аудио.
**Why:** `AVAudioPlayer` сам разбирается с форматами (моно-голос, стерео-музыка, любые импортированные файлы), даёт зацикливание, громкость и плавное затухание. AVAudioEngine потребовал бы ручной конвертации форматов.
**What was rejected:** AVAudioEngine с двумя player-нодами (сложнее, нет выигрыша для данного сценария); SwiftData (достаточно JSON).

## 2026-10-11 — Обратное воспроизведение
**What was decided:** Развёрнутая копия (CAF, 16 бит) строится кусками с конца файла, лежит в Caches, оригинал не трогается; готовится при включении переключателя и заранее при запуске сессии.
**Why:** сохраняет скорость и высоту голоса; не зависит от длины; кеш можно потерять без последствий.
**What was rejected:** `AVAudioPlayer.rate = -1` (не работает), разворот в памяти целиком.

## 2026-10-11 — Встроенная музыка
**What was decided:** синтез трёх эмбиент-петель скриптом `Tools/generate_music.py`.
**Why:** без интернета нельзя получить лицензированные треки; собственный синтез даёт чистые права.
**What was rejected:** скачивание CC0-треков (нет доступа к сети/нельзя проверить лицензию).

## 2026-10-11 — Тишина в паузах без музыки
**What was decided:** если музыка не выбрана, в сессии играет беззвучный зацикленный WAV.
**Why:** чтобы система не приостановила приложение при заблокированном экране в паузах до 10 с. **Требует проверки на реальном iPhone.**

## 2026-10-11 — Библиотека текстов
**What was decided:** 178 текстов пользователя встроены в приложение, 11 категорий; список «хочу записать» на главном экране; форма «Ты» без изменений; №102 дописан как «…позитивную реальность.»; №59–64 (от лица диктора) вынесены в категорию «Настройка на запись».
**Why:** по прямой просьбе владельца; снимает исходное ограничение «без готовых аффирмаций».
**What was rejected:** плоский список с поиском; запись названия без показа текста.
